Suppose that we need to calculate the value of the expression <span class="tex-span"><i>a</i> <i>tor</i> <i>b</i></span>. Both numbers <span class="tex-span"><i>a</i></span> and <span class="tex-span"><i>b</i></span> are written in the ternary notation one under the other one (<span class="tex-span"><i>b</i></span> under <span class="tex-span"><i>a</i></span>). The result of summing each two digits is calculated modulo 3. Note that there is no carry between digits (i. e. during this operation the digits aren't transferred).
